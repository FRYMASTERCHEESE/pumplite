# PumpLite

Low-fee token launchpad.

## Current Solana functionality

PumpLite can create real SPL tokens on Solana Mainnet.

The creator connects a compatible Solana wallet and signs the transaction.

The token mint is created directly on Solana.

## Current trading status

Real PumpLite bonding-curve trading is currently disabled.

The next development stage is the PumpLite Solana on-chain program.

That program will provide:

- Real SOL buys
- Real SOL sells
- On-chain bonding curve
- Slippage protection
- Creator fee
- PumpLite treasury fee
- Market/liquidity reserve
- On-chain fee enforcement

## Fee model

Total trading fee: 0.25%

Creator: 0.10%

PumpLite treasury: 0.05%

Market/liquidity reserve: 0.10%

Token creation fee: 0

Referral fee: 0

## Important

Never put private keys, seed phrases, wallet passwords or API secrets into this repository.

GitHub Pages hosts the frontend. Blockchain transactions still require network fees.
